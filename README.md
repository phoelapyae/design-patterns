# Gang of Four Design Patterns

This repository keeps each Gang of Four design pattern implementation on its own Git branch. The `main` branch is the navigation index.

## How to Use

Open a pattern branch from the links below, or check it out locally:

```bash
git fetch origin
git checkout patterns/iterator
```

Replace `patterns/iterator` with the branch name for the pattern you want to explore.
